# Phishing Samples — Social Engineering Classification Lab (P2)

In this lab you will read 5 phishing samples and file a GitHub Issue for each one, classifying the social engineering tactic used and the psychological trigger exploited. Reference the **S.E.T. framework** (see `SET-FRAMEWORK.md`) in every Issue.

## How the lab works

1. Open this repo in **Codespaces** (Code → Codespaces → Create codespace).
2. Read each file in `emails/` — they are numbered `email-1.txt` … `email-5.txt`.
3. For each email, open a **new GitHub Issue** in your fork:
   - Title: `Email N — <tactic name>`
   - Body must include:
     - **Tactic:** the primary S.E.T. tactic used
     - **Trigger:** the psychological instinct it exploits
     - **Red flags:** at least 2 concrete indicators (domain tricks, urgency, sender details…)
4. Your teacher reviews the Issues to check understanding.

All samples are teacher-drafted fakes based on publicly documented campaigns. No live malicious content.
