# Phishing Samples — Social Engineering Classification Lab (P2)

In this lab you will read 5 phishing samples and file a GitHub Issue for each one on THIS repo, classifying the social engineering tactic used and the psychological trigger exploited. Reference the **S.E.T. framework** (see `SET-FRAMEWORK.md`) in every Issue.

## How the lab works

1. Open the repo at https://github.com/ivycollegiate-development/phishing-samples — **do NOT fork it.** Everyone files Issues on this one repo so the whole class's work is visible for in-class review. You are not editing any code, so no fork (and no Codespace) is needed.
2. Read `SET-FRAMEWORK.md` — the S.E.T. taxonomy you will use in every Issue.
3. Read each file in `emails/` — they are numbered `email-1.txt` … `email-5.txt`.
4. Go to the **Issues tab** (https://github.com/ivycollegiate-development/phishing-samples/issues), click **New issue**, and file **one Issue per email — 5 Issues total**:
   - Title: `Email N — <tactic name>`
   - Body must include:
     - **Tactic:** the primary S.E.T. tactic used
     - **Trigger:** the psychological instinct it exploits
     - **Red flags:** at least 2 concrete indicators (domain tricks, urgency, sender details…)
5. Submit on Google Classroom: paste the links to your 5 Issues.

Your teacher reviews the Issues on this repo to check understanding.

All samples are teacher-drafted fakes based on publicly documented campaigns. No live malicious content.
